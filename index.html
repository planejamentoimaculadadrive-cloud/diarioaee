🔗 Conexão com Google Sheets

📋 URL do Apps Script (Web App)

Cole aqui a URL gerada ao implantar o Apps Script como Web App no Google Sheets.

⬆ Cole a URL acima para ativar a integração.
📖 Como configurar passo a passo:
  1. Acesse sheets.google.com e crie uma planilha em branco
  2. Clique em Extensões → Apps Script
  3. Apague o código existente, cole o código Apps Script e execute criarPlanilha()
  4. Autorize as permissões solicitadas pelo Google
  5. Clique em Implantar → Nova implantação → App da Web
  6. Em "Quem tem acesso" selecione Qualquer pessoa
  7. Clique em Implantar e copie a URL gerada
  8. Cole a URL no campo acima e clique em Testar Conexão
